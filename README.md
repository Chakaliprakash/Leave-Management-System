# Student and Hostel Management System

A legacy Java web application for student registration, login, hostel-related records, and administration workflows.

## Features

- Student registration and login.
- Student record lookup and administration.
- Hostel-related student allocation and management.
- Complaint and feedback workflows.
- Java Servlet/JSP web interface with DAO-based data access.

## Technology Stack

- Java Servlets and JSP
- JDBC and MySQL
- HTML, CSS, and JavaScript
- Eclipse Dynamic Web Project structure

## Project Structure

The application is under `Leave-managent-system-master/`. Web pages and assets are in `WebContent/`; Java business objects, controllers, and DAO classes are under `src/`.

## Setup Notes

This repository uses a legacy Eclipse web-project layout and includes older library JARs. To run it, import the project into a compatible Java web IDE, configure a servlet container and MySQL database, and review the database utility and deployment descriptors before starting it.

No automated setup or test command is currently documented in the repository.
